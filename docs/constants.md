# Constants

Указывает на `const` конструкцию.
Указывает на все глобальные объявления констант или констант внутри класса.
В случае константы класса включает в себя все дочерние элементы, такие как:
- Определение типа
- Определение значения по умолчанию
- Модификаторы доступа

### Contexts

- [Namespace](namespaces.md)
- [Classes](classes.md)

##### Пример

Xpath:
```php
name
```

Кодовая база:
```php
<?php

namespace A\B;

class C {
    // start
    const USER = 'user';
    // end
}
```

или

```php
define('APP_DEBUG', '1');
```

## Declared type

Указывает на определение типа свойства.

##### Пример

- `USER[type]`

## Value

Указывает на определение значения свойства по умолчанию.

##### Пример

- `USER[value]`
