### Class

Указывает на `class` конструкцию.
Указывает на всё объявление `class`, включая все его дочерние элементы.

##### Пример

Xpath:
`C`

Кодовая база:
```php
<?php

namespace A\B;

// start
class C {}
// end
```

или

```php
<?php

namespace A\B {
    // start
    class C {}
    // end
}
```
